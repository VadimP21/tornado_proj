By docker:

Запустите контейнер с PostgreSQL, используя команду docker run. Например:

docker run --name my-postgres-container -e POSTGRES_PASSWORD=mysecretpassword -p 5432:5432 -d postgres

Подключитесь к контейнеру с помощью команды docker exec, чтобы выполнить команды внутри контейнера:

docker exec -it my-postgres-container psql -U postgres
