 Подключение к интерактивной(-i) оболочке внутри контейнера с присвоением имени хосту(-h):
 docker run -h HOST -i -t debian bash

 Список запущенных [-a запущеных] контейнеров:
 docker ps [-a]

 Список images:
 docker images


 Показывает изменения в контейнере:
 docker diff <container_name>

 Сбор логов:
 docker logs <container_name>

 Запуск контейнера
 [--rm удален по выходу из него],
 [-p5050:5000 назначение портов - хоста и контейнера соответственно],
 [-e передача значения <val> в переменную окружения <var_name>]:

 docker run [-p5050:5000] [-e "<var_name>=<val>"] [--rm] <container_name>

 Перезапуск контейнера:
 docker start <container_name>

 Удаление контейнера (не запущенного),
 [... всех контейнеров, у которых status=exited]:
 docker rm [$(docker ps -a -f status=exited -q)]

 Создание образа из dockerfile,
 [-t <container_name> присвоение имени контейнеру],
 docker build [-t <container_name>] .

 Изменение названия репозитория
 (например для выгрузки его в DockerHub, <rep_new_name> - название репозиторя на DockerHub)
 docker tag <rep_name> <rep_new_name>

 Выгрузка репозитория в DockerHub:
 docker push <rep_name>

 Удаление image, указав его ID или тег:
 docker rmi <image_id_or_tag>
